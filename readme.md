# Trabajo Práctico N°1 – Algoritmos y Estructuras de Datos
El sistema permite:
- Leer los archivos `productos.bin` y `reparaciones.bin`.
- Ordenar las reparaciones por **cliente**, **tipo de producto** y **SKU**.
- Consultar todas las reparaciones de un cliente determinado.
- Calcular y mostrar la **ganancia total** obtenida con ese cliente.
- Informar si el cliente no existe en los registros.

## 🧠 Conceptos aplicados
- Uso de **estructuras (struct)** y **vectores**.  
- Manejo de **archivos binarios**.  
- Implementación de **funciones plantilla (templates)**.  
- **Ordenamiento** y **búsqueda lineal** con criterios personalizados.
