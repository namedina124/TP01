# Trabajo Práctico Nº1 – Algoritmos y Estructuras de Datos

## 📌 Descripción
El sistema permite:

- Leer los archivos binarios `productos.bin` y `reparaciones.bin`.
- Ordenar las reparaciones por cliente, tipo de producto y SKU.
- Consultar todas las reparaciones de un cliente determinado.
- Calcular y mostrar la ganancia total obtenida con ese cliente.
- Informar cuando el cliente no existe en los registros.

El programa finaliza al ingresar la señal de fin de archivo (EOF).

## 🧠 Conceptos aplicados

- Uso de **estructuras (`struct`)**.
- Manejo de **arreglos comunes de C**.
- Lectura de **archivos binarios**.
- Implementación de **funciones plantilla (templates)**.
- **Ordenamiento** y **búsqueda lineal ordenada** mediante criterios personalizados.
